# TAGS — the controlled vocabulary

Small and stable, like the realism base's. Seven **cut-tags** (umbrellas, one per ANATOMY cut)
+ named **instance** tags + two **method** tags (applied wherever the base does its two
signature moves). Tag a quote with both its umbrella and any instance it names. Keep this list
short; add a tag only when a motif recurs across voices.

| tag | the cut / motif it names | whose / where |
|---|---|---|
| `source-of-rule` | where legitimate kingship comes from (Cut 1) | all |
| `sword-and-sovereignty` | the stone / Excalibur / Caliburn: election vs. conferred-and-revocable power | Malory, Geoffrey |
| `the-fellowship` | the order built against precedence and its built-in fracture (Cut 2) | Malory, Chrétien, Wace, SGGK |
| `pentecostal-oath` | the Round Table's constitution — and every clause broken | Malory III.xv |
| `the-grail` | the highest good; the quest that depletes the world it perfects (Cut 3) | Vulgate, Wolfram, Malory, the Queste |
| `the-unasked-question` | the Grail-failure as a failure of attention / compassion | Wolfram, Peredur *(Chrétien's Perceval off-corpus)* |
| `courtly-love` | eros as ennobling and as the founding betrayal (Cut 4) | Chrétien, the Vulgate, Malory, Gottfried |
| `the-wound-and-wasteland` | the king's body = the land; the maim that sterilizes (Cut 5) | Malory, Wolfram, Geoffrey |
| `dolorous-stroke` | Malory's wound-instance that lays three kingdoms waste | Malory II.xvi |
| `once-and-future` | deferred restoration; messianic kingship-in-suspension (Cut 6) | Geoffrey, Malory, Layamon |
| `foreknowledge-and-doom` | the prophet who cannot use his prophecy; fate (Cut 7) | Geoffrey, Malory |
| `disenchantment` | magic withdrawing; the Grail-less modern age (as Merlin goes) | Malory |
| `pseudo-history` | the chronicle Arthur claimed as history — and Gildas's telling silence | the Chroniclers |
| `the-chivalric-test` | the code tried on a single knight (the beheading-game, the green girdle) | SGGK, the Gawain romances |

**Cross-tag note** (as in realism): `source-of-rule` is the umbrella over `sword-and-sovereignty`;
`the-grail` over `the-unasked-question`; `the-wound-and-wasteland` over `dolorous-stroke`. The two
method tags mark where the base does its signature work — *name the variants* (`version-divergence`)
and *count the cost* (`the-cost`) — and may sit on any quote regardless of cut.
